# Data and source policy

原資料や外部DBの本文・画像・レコード群を大量複製しません。出典については資料名、著者、年代、所蔵・提供機関、URL、外部ID、該当位置、権利情報を保存します。不明な書誌情報は `null` のままにします。アクセス日を記録し、リンク切れは書誌IDと機関名から追跡します。

出典URLはその資料を確認できる公開ページを優先します。一次資料への導線が機関解説からしか確認できない場合、機関解説を二次資料として登録し、主張は「機関がそのように紹介している」と限定します。ページにない内容を出典へ帰属させません。

このCorpusのオリジナル記述はCC0 1.0です。外部資料の権利は継承せず、各機関の利用条件を確認してください。外部資料を再利用する際は各提供元へ帰属を示してください。
