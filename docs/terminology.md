# Terminology / 用語

| Term | Meaning in this index |
| --- | --- |
| 妖怪 / yōkai | 単一の学術定義に固定しない伝承上の存在・現象の便宜的な総称 |
| 怪異 / kaii | 異常な出来事・現象を含む広い語 |
| 怨霊 / onryō | 死者の霊として語られる伝承上の表象。歴史的事実の判定ではない |
| source_fact | 出典の記述・図像について直接確認できること |
| established_view | 出典に基づく既存の研究・機関解説上の見解 |
| inference | 資料から導く解釈 |
| hypothesis | 検証待ちの仮説 |

日本語原語を `name_ja` に保持します。`name_romaji` は検索補助、`claim_en` は任意の翻訳です。訳語によって伝承の境界や同一性が変わる場合、同一とみなさずIssueで検討します。
